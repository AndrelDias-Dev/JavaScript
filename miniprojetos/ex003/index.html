HTML (HyperText Markup Language): é a linguagem usada para criar a estrutura de um site. Ele organiza os elementos que aparecem na página, como títulos, textos, imagens, links, tabelas, formulários e botões. Pode ser comparado ao esqueleto de uma página web.

CSS (Cascading Style Sheets): é a linguagem responsável pela aparência do site. Com ela é possível definir cores, fontes, tamanhos, espaçamentos, animações e layouts responsivos, deixando a página mais bonita e organizada visualmente.

JavaScript: é a linguagem de programação que adiciona interatividade e funcionalidades ao site. Com JavaScript é possível criar menus interativos, validação de formulários, animações, atualizações automáticas e diversas ações dinâmicas que tornam a página mais funcional.

React: é uma biblioteca JavaScript utilizada para criar interfaces modernas e dinâmicas de forma mais organizada. Ela trabalha com componentes reutilizáveis, facilitando o desenvolvimento e a manutenção de aplicações web grandes e complexas.
